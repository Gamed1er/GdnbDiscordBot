## 🏆 使用者升級系統 (Level System)
用於活絡社群氣氛的經驗值系統。當玩家在伺服器中發言時，系統會自動賦予經驗值（XP），並在達到門檻時自動升級。

### ⚙️ 技術亮點
* **多伺服器獨立儲存**：每一座伺服器的資料皆獨立封裝成一組 JSON 檔案，方便擴充與管理。
* **通知免打擾開關**：玩家可以使用指令自由切換是否在升級時接收機器人的慶賀廣播。
* **防刷等級機制**：內建發言冷卻時間（Cooldown），防止玩家透過惡意洗版快速刷取經驗值。

### 📃 使用方式
* 玩家輸入 `/xp` 查看自己目前的等級與當前經驗值進度條。
* 玩家輸入 `/xp_announcement` 即可開啟或關閉升級通知。
* 經驗值的計算與轉化寫在 `core/level_manager.py` 之中

**資料儲存結構 (data/level_system/<server_id>.json)：**
```json
{
  "user_id_123456789": {
    "xp": 450,
    "level": 3,
    "notify": true
  }
}

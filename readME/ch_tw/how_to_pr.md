在 GitHub 上進行 **PR (Pull Request)**，簡單來說就是把你修改好的程式碼，提交給專案原作者審查並合併的過程。

以下為你整理最標準、也是最常用的 **Git 指令搭配網頁操作** 的完整流程：

---

## 步驟一：Fork 專案（在 GitHub 網頁上）

如果你沒有該專案的寫入權限（通常是開源專案或別人的專案），你需要先複製一份到自己的帳號下。

1. 打開你想貢獻的 GitHub 專案頁面。
2. 點擊右上角的 **Fork** 按鈕。
3. 選擇你的個人帳號，這樣你的 GitHub 就會多出一個一模一樣的專案副本。

---

## 步驟二：Clone 專案到本機（使用終端機/命令列）

把你在 GitHub 上 Fork 出來的複本下載到電腦裡進行修改。

1. 在你 **Fork 後的專案頁面**，點擊綠色的 **Code** 按鈕並複製 HTTPS 或 SSH 網址。
2. 打開終端機（Terminal），輸入以下指令：
```bash
git clone <你複製的網址>
cd <專案資料夾名稱>

```



---

## 步驟三：建立新分支（Branch）

**強烈建議不要直接在 `main` 或 `master` 分支上修改。** 建立一個新分支可以讓你的 PR 目的更明確。

```bash
# 建立並切換到新分支，名稱可以反映你要修改的內容（例如：update-readme）
git checkout -b <新分支名稱>

```

---

## 步驟四：修改檔案並提交（Commit）

1. 使用你習慣的編輯器（如 VS Code）修改檔案。
2. 修改完成後，回到終端機查看狀態並提交：

```bash
# 查看有哪些檔案被修改了
git status

# 將修改的檔案加入暫存區（. 代表全部，也可以指定單一檔名）
git add .

# 提交修改，並寫下清晰的 Commit 訊息
git commit -m "修正：更新了說明文件中的語法錯誤"

```

---

## 步驟五：Push 分支到 GitHub

將你本機的新分支上傳到你 GitHub 的遠端儲存庫。

```bash
git push origin <你的新分支名稱>

```

---

## 步驟六：正式發起 Pull Request（在 GitHub 網頁上）

1. 回到你 GitHub 的 **Fork 專案網頁**。
2. 你會看到頂端出現一個黃色提示框，寫著 `Compare & pull request`，直接點擊它。
*(如果沒看到，可以點擊專案標題下方的 **Pull requests** 分頁，再點擊綠色的 **New pull request**)*。
3. **檢查設定：**
* **base repository:** 原作者的專案與主要分支（通常是 `main`）。
* **head repository:** 你的專案與你剛剛建立的 `<新分支名稱>`。


4. 填寫這個 PR 的**標題**與**詳細描述**（告訴原作者你改了什麼、為什麼要改）。
5. 點擊 **Create pull request**。

---

恭喜你！這樣就完成了 PR。接下來就是等待專案管理員（Maintainer）審查你的程式碼。如果他們提出修改建議，你只需要在**同一個本地分支**上修改、再次 `commit` 並 `push`，該 PR 就會自動更新，不需要重新發起一個新的 PR。

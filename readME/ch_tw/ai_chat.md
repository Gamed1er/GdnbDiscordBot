## 💬 Gemini 聊天頻道 (AI Chat)
讓你的 Discord 伺服器成員能夠與先進的 AI 進行互動與聊天。管理員可以指定一個專屬頻道，該頻道內的所有對話都會交由 Gemini 處理。

### ⚙️ 技術亮點
* **獨立記憶空間**：為每一位使用者建立獨立的對話上下文記憶（AI Memory），每位玩家與 AI 的對話進度互不干擾。
* **負載平衡機制**：支援同時載入多個 Gemini API Key，每次對話會隨機抽取可用 Key 呼叫，有效分散單一 Key 的流量限制（429 錯誤）。

### 📃 使用方式
1. 管理員在目標頻道輸入 `/ai_channel_register` 進行頻道登記。
2. 使用者在該頻道發言後，AI 會自動讀取並更新 `data/ai_memory/<user_id>.json` 的記憶檔案。

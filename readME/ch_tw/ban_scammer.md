## 🚨 自動防詐騙陷阱 (Ban Scammer)
這是一個強力的自動化社群防衛工具。用於針對目前 Discord 上極為猖獗的「Token 遭竊、亂入伺服器發送假 Nitro 詐騙連結」的帳號進行瞬間秒殺。

### ⚙️ 技術亮點
* **陷阱頻道設計 (Honey Pot)**：建立一個一般正常成員絕對不會去點擊或發言的陷阱頻道（例如：隱藏的驗證頻道、或是公告純讀取頻道）。
* **零容忍自動封鎖**：只要有任何人（通常是自動化詐騙 Bot）在該頻道內發送任何一則訊息，機器人會瞬間將其予以 `Ban`（封鎖）處分，將災情阻絕於起點。

### 📃 使用方式
* 目前版本的防詐騙頻道 ID 採硬編碼（Hard-coded）形式寫在程式碼中。
* 你可以修改 `cogs/ban_scammer.py` 中的 `TRAP_CHANNEL_ID` 來指定你伺服器的陷阱頻道。

## 🎮 地圖發布與評分系統 (Map System)
專為 Minecraft 地圖創作者設計的管理工具。管理員可以透過視覺化精靈發布地圖，產出精美的 Embed 介紹卡，並附帶互動按鈕（View）。

### ⚙️ 技術亮點
* **Persistent View（持久化按鈕）**：採用 discord.py 的 Persistent View 設計。即使機器人重啟、當機或更新，地圖卡片底下的「下載」與「評分」按鈕依然能正常運作，不需重新發布。
* **下載驗證與追蹤**：點擊下載會即時累加統計數據。
* **動態評分機制**：玩家點擊評分按鈕後，會彈出 Modal 視窗收集分數，並自動即時計算並更新該地圖的平均星等。

### 📃 使用方式
1. 管理員於頻道中輸入 `/setup_map` 啟動發布精靈。
2. 地圖檔案與統計數據將會自動建立於 `data/projects/<地圖名稱>/` 目錄下。

**配置範例**
在 data/projects/<地圖名稱> 底下，可以加入數個檔案 (建議是壓縮檔案)，例如
```
data/projects/
└── 3d_mine_sweeper/
    ├── thumbnail.png
    ├── 踩地雷地圖檔.zip
    └── 踩地雷資源包.zip
```
其中必須包含 `thumbnail.png` 來做為插圖使用

之後在該資料夾中會產生 `statistics.json` 檔案，該檔案作為記錄數據使用
